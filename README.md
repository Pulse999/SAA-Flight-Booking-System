# ✈️ South African Airways Flight Booking System

A practical software engineering project for a flight booking system, developed using **C#, PostgreSQL, Git, GitHub, and Azure DevOps**.

The project focuses on applying software development, database design, version control, and DevOps practices to a realistic airline booking scenario.

---

## 📌 Project Overview

The South African Airways Flight Booking System is designed to manage core flight booking operations, including:

- Passenger information
- Airport information
- Flight details
- Bookings
- Tickets
- Payments

The system uses a relational PostgreSQL database to maintain structured data and relationships between the different parts of the booking system.

The project is being developed incrementally, with development work managed using Git branches, pull requests, code reviews, and Azure DevOps.
